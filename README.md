# Starter Landing Page (React + Vite + Tailwind)

## Jalankan
    npm install
    npm run dev        # buka http://localhost:5173
    npm run build      # hasil di folder dist/

## Ganti isi per klien
Edit `src/site.js` (nama, teks, warna, nomor WhatsApp, layanan, testimoni, FAQ).
Edit juga `<title>` dan meta di `index.html`.

## Deploy gratis
Push ke GitHub, lalu import repo di Vercel atau Netlify.
Build command: `npm run build`, output: `dist`.
